# Snake

My third project. I went in thinking I wasn't that bad at JS game dev after
Pong, but there's a huge difference between constantly rendering frame by
frame vs. having to do it per tick.

## Controls

- **Tab** — Dev tools
- **Space** — Pause
- **R** — Restart (only when game over; ignored otherwise)
